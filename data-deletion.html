데이터 삭제 안내

쉐도잉랩(ShadowingLab) · 개발자: YBG Ltd

쉐도잉랩은 별도의 회원가입 없이 기기(로컬) 중심으로 동작하는 앱으로, 사용자가 업로드한 파일과 학습 데이터는 대부분 사용자 본인의 기기에만 저장됩니다. 아래 안내에 따라 언제든 직접 데이터를 삭제하실 수 있습니다.

1. 앱 내에서 데이터 삭제하는 방법

  1. 쉐도잉랩 실행 → 홈 화면으로 이동
  2. 삭제하고 싶은 파일 카드에서 🗑 삭제 아이콘을 탭하거나, 카드를 왼쪽으로 스와이프
  3. 확인 팝업에서 삭제 선택 — 해당 파일과 관련된 문장 분리 결과, 학습 진행 상태가 즉시 삭제됩니다

2. 전체 데이터를 한 번에 삭제하는 방법

앱을 삭제(제거)하시면 기기에 로컬로 저장된 모든 데이터(업로드 파일, 문장 분리 결과, 학습 기록·통계, 설정값)가 함께 삭제됩니다. 별도의 서버 계정이 없어 앱 삭제만으로 데이터가 완전히 제거됩니다.

3. 삭제/보관되는 데이터 유형

데이터 유형보관 위치삭제 방법보관 기간
업로드한 음성/영상 파일기기 로컬 저장소앱 내 삭제 버튼 또는 앱 삭제사용자가 삭제할 때까지
문장 분리 결과, 학습 기록/통계기기 로컬 저장소앱 내 삭제 버튼 또는 앱 삭제사용자가 삭제할 때까지
인앱 구매(광고 제거) 상태Google Play 결제 시스템Google Play 계정에서 관리Google Play 정책에 따름
광고 식별자(광고 ID)Google AdMob(제3자)기기 설정의 광고 개인최적화 해제Google 정책에 따름
본 서비스는 오디오/영상 콘텐츠 분석을 서버로 전송하지 않고 전량 기기 내(온디바이스)에서 처리하므로, 회사가 별도로 보관·저장하는 사용자 콘텐츠가 없습니다.
